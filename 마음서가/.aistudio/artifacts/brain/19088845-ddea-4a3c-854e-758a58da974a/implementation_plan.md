# 마음 서가(Mind Bookshelf) AI 관리자 페이지 구현 계획

사용자가 마음 서가 서비스의 AI 동작 방식(시스템 프롬프트, AI 추천 지침, 기본 모델 및 추론 강도)을 직접 세밀하게 조정하고, 이를 서버에 영구 보관하여 모든 방문자에게 공통 반영할 수 있는 **AI 관리자 페이지**를 구현합니다.

---

## 1. 아키텍처 및 핵심 요구사항

### 1) 진입 및 보안 방식
- **상단 헤더 관리자 버튼**: 네비게이션 우측에 자물쇠 아이콘 형태의 `관리자 모드` 버튼 배치.
- **비밀번호 인증 모달**:
  - 관리자 진입 시 비밀번호 확인 대화상자 노출.
  - 기본 비밀번호(예: `admin1234`, 환경변수 `ADMIN_PASSWORD` 지원).
  - 인증 성공 시 세션 토큰(또는 암호화 검증 키)을 프론트엔드 세션 스토리지에 유지하여 탭을 닫기 전까지 재인증 없이 관리 가능.

### 2) 설정 데이터 영구 보관 (서버 사이드)
- **저장 위치**: `ai-config.json` (프로젝트 루트).
- **영구 지속성**: 서버 재시작 시에도 유지되며, 파일이 없을 경우 기본 프리셋(Default Preset)으로 자동 생성.
- **전역 반영**: `/api/recommend` 추천 요청 시 실시간으로 저장된 `ai-config.json`의 설정을 읽어 모든 방문자의 도서 추천 생성에 공통 적용.

### 3) 세밀 조정 가능한 AI 파라미터
1. **시스템 프롬프트 (System Instruction)**:
   - 마음 서가 AI 사서의 페르소나, 어조(따뜻한 공감형, 직관적 해법형 등), 추천 기준 및 제약 조건 직접 수정.
   - [기본값으로 초기화] 버튼 제공.
2. **기본 AI 모델 선택**:
   - `gemini-3.1-flash-lite` (초고속 추천, 기본 권장)
   - `gemini-3.8-flash` (고품질 다각도 분석)
   - Claude 옵션 연동 (사용자 API 키 입력 시)
3. **추론 강도 (Thinking Level)**:
   - `MINIMAL` (초고속 응답: 1~2초대)
   - `LOW` (경량 추론: 균형잡힌 속도와 깊이)
   - `MEDIUM` / `HIGH` (심층 사색 및 분석적 큐레이션)
4. **추천 권수 및 온도(Temperature)**:
   - 추천 도서 권수 (3권 기본, 2~5권 선택 가능)
   - 창의성 수치 (0.0 ~ 1.0)

## 2. 세부 개발 단계

### 1단계: 백엔드 API 및 영구 설정 관리 (`server.ts`)
- **설정 모듈 추가**:
  - `loadAIConfig()`: `ai-config.json`을 읽고 유효성 검사 후 기본값 병합.
  - `saveAIConfig(newConfig)`: 관리자가 수정한 설정을 안전하게 파일에 원자적(atomic) 기록.
- **관리자 엔드포인트 구현**:
  - `POST /api/admin/login`: 관리자 비밀번호 검증 및 일회용 세션 토큰 발급.
  - `GET /api/admin/config`: 현재 적용 중인 AI 설정값 조회 (관리자 인증 불필요 공개 또는 토큰 검증).
  - `POST /api/admin/config`: 새로운 AI 설정값 저장 (헤더 토큰 또는 패스워드 인증 필수).
  - `POST /api/admin/reset`: 기본 추천 프롬프트 및 파라미터로 리셋.
- **추천 엔드포인트 연동 (`POST /api/recommend`)**:
  - 하드코딩된 시스템 프롬프트 대신 `loadAIConfig()`에서 가져온 실시간 시스템 프롬프트, 모델, ThinkingLevel, Temperature를 동적 적용.

### 2단계: 관리자 UI 컴포넌트 개발 (`src/components/AdminModal.tsx`)
- **인증 화면 (Login View)**:
  - 비밀번호 입력 필드, 틀릴 경우 안내 메시지, 보안 팁 안내.
- **대시보드 화면 (Admin Dashboard View)**:
  - **헤더**: 'AI 서가 관리자 콘솔' 타이틀, 현재 활성 모델 뱃지, 로그아웃 버튼, 닫기 버튼.
  - **탭 1: 프롬프트 & 지침 설정 (Prompt & Persona)**:
    - 시스템 프롬프트 텍스트에리어 (에디터 스타일, 실시간 글자수 카운트).
    - 프롬프트 가이드 툴팁 (사용 가능한 변수 및 규칙 설명).
    - '기본값 불러오기' 버튼.
  - **탭 2: 모델 & 추론 엔진 설정 (Engine & Parameters)**:
    - AI 모델 선택 라디오/셀렉트 박스.
    - 추론 강도 (Thinking Level) 슬라이더 또는 단계별 버튼 (MINIMAL, LOW, MEDIUM, HIGH) + 예상 소요시간 안내.
    - 추천 도서 개수 (2~5권) 및 Temperature 조절 바.
  - **탭 3: 실시간 테스트 샌드박스 (Live Test)**:
    - 변경한 설정값을 저장하기 전에 관리자 창 내에서 즉시 고민을 입력하고 AI 추천 결과를 미리보기로 테스트해볼 수 있는 미니 테스트 패널.
  - **하단 액션바**:
    - [설정 저장 및 전체 적용] 버튼 (누르면 즉시 토스트 알림과 함께 서버 반영).
    - [초기화] 버튼.

### 3단계: 메인 앱 UI 연동 (`src/App.tsx`)
- 헤더 우측에 `관리자 설정` 아이콘 버튼 추가 (감성적인 서가 디자인을 해치지 않는 절제된 아이콘 디자인).
- 관리자 모달 상태 (`isAdminOpen`) 바인딩.
- 추천 요청 시 서버에 설정된 모델명과 추론 강도가 메인 화면에도 실시간 동기화되어 표시되도록 연동.

## 3. 검증 및 테스트 계획

1. **빌드 및 타입 체크**:
   - `compile_applet` 및 `lint_applet` 동시 실행으로 TypeScript 문법 및 React 컴포넌트 이상 유무 검증.
2. **관리자 인증 검증**:
   - 올바른 비밀번호 입력 시 정상 로그인 및 대시보드 진입 확인.
   - 잘못된 비밀번호 입력 시 차단 및 오류 알림 표시 확인.
3. **설정 영구 저장 및 실시간 반영 검증**:
   - 관리자 페이지에서 시스템 프롬프트 어조를 변경(예: "모든 추천 이유 끝에 마음을 따뜻하게 하는 한 문장의 응원을 덧붙이세요") 후 저장.
   - 메인 화면에서 새로운 고민을 입력하고 도서 추천을 요청하여 변경된 프롬프트 지침이 즉각 반영되는지 확인.
   - 서버를 재시작하거나 브라우저를 새로고침해도 설정이 유지되는지 `ai-config.json` 파일 확인.
4. **추론 강도(Thinking Level) 변경 테스트**:
   - `MINIMAL`과 `LOW` 간 전환 시 정상 동작 및 응답 속도 확인.
